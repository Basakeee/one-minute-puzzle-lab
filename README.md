# One Minute Puzzle Lab

Static HTML prototype for five simple 2D puzzle game ideas designed to end in under one minute per stage.

Clearing a stage automatically starts the next stage of the same selected puzzle. Each puzzle has five map variants, then repeats the hardest layout while the timer keeps tightening from 60 seconds down to a 30 second minimum.

## Ideas

- `ลังหนีประตู`: mini Sokoban. Push one crate onto a goal tile, then reach the exit.
- `ต่อไฟ 5 จุด`: toggle all circuit nodes on.
- `กุญแจสามสี`: collect all keys before exiting.
- `สะพานสลับสี`: switch which color bridge is passable.
- `จำลำดับรูน`: press runes in order, then exit.

## Controls

- Move: arrow keys, WASD, or on-screen arrow buttons.
- Interact: Space, Enter, or Action.
